# Emotion Detection System

## Overview
This project is a text-based Emotion Detection System developed using Python. The application analyzes user-entered text and identifies emotions such as Happy, Sad, Angry, or Neutral based on keyword analysis.

## Features
- Text emotion analysis
- Multiple emotion categories
- Interactive user input
- Real-time emotion detection
- Simple NLP-based processing

## Technologies Used
- Python 3.x
- Functions
- Lists
- String Manipulation
- Conditional Statements

## How to Run
1. Install Python 3.x.
2. Run the Python script.
3. Enter a sentence.
4. View the detected emotion.

## Supported Emotions
- Happy
- Sad
- Angry
- Neutral

## Learning Outcomes
- Natural Language Processing fundamentals
- Text classification concepts
- String processing techniques
- Python application development
