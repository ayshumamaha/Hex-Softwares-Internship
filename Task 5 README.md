# Face Detection System

## Overview
This project implements a Face Detection System using Python and OpenCV. The application detects faces present in an image and displays the detection results.

## Features
- Face detection in images
- Multiple face support
- Image processing
- Face counting
- Detection visualization

## Technologies Used
- Python 3.x
- OpenCV
- Haar Cascade Classifier

## How to Run
1. Install Python 3.x.
2. Install OpenCV.
3. Place an image in the project directory.
4. Run the Python script.
5. View detection results.

## Applications
- Surveillance systems
- Security solutions
- Photo tagging
- Attendance systems

## Learning Outcomes
- Computer Vision basics
- Image processing concepts
- OpenCV implementation
- Face detection techniques
