# AI Chatbot

## Overview

This project is a simple AI Chatbot developed using Python. The chatbot interacts with users by recognizing keywords in user queries and providing predefined intelligent responses. It demonstrates the fundamentals of Natural Language Processing (NLP), text processing, and conversational AI.

## Features

* Interactive chatbot conversation
* Keyword-based response generation
* User-friendly command-line interface
* Continuous conversation loop
* Exit functionality

## Technologies Used

* Python 3.x
* Dictionaries
* Functions
* Loops
* Conditional Statements

## How to Run

1. Install Python 3.x.
2. Download the project files.
3. Run the Python script.
4. Start chatting with the bot.
