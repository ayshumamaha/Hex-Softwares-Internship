# Fraud Detection System

## Overview

This project simulates a basic fraud detection system using Python. Transactions are analyzed based on predefined rules and classified as legitimate or fraudulent. The project demonstrates data processing and decision-making logic.

## Features

* Transaction analysis
* Fraud classification
* Automated decision making
* User-friendly output display

## Technologies Used

* Python 3.x
* Functions
* Lists
* Conditional Statements
* Loops

## How to Run

1. Install Python 3.x.
2. Run the Python script.
3. View transaction analysis results.

## Fraud Detection Logic

Transactions exceeding a predefined threshold are marked as fraudulent, while others are classified as legitimate.

## Learning Outcomes

* Data analysis concepts
* Rule-based classification
* Python programming fundamentals
* Decision-making algorithms
