# AI-Powered Virtual Assistant

## Overview

This project is a command-line AI Virtual Assistant developed using Python. The assistant can respond to greetings, display current time, perform calculations, and simulate opening websites through text commands.

## Features

* Greeting responses
* Current time display
* Mathematical calculations
* Website command handling
* Interactive user interface

## Technologies Used

* Python 3.x
* Datetime Module
* Functions
* Conditional Statements
* Loops

## How to Run

1. Install Python 3.x.
2. Execute the Python script.
3. Enter commands and interact with the assistant.

## Supported Commands

* hello
* what is the time
* calculate expressions
* open google
* bye

## Learning Outcomes

* Command processing
* Automation concepts
* User interaction design
* Python application development
